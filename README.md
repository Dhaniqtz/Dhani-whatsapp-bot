# Dhani-whatsapp-bot

🤖 DHANI BOT

A powerful modular WhatsApp bot built with Node.js.

✨ Features

- 🔗 WhatsApp Pairing Code
- 👑 "/owner" — Show bot owner profile
- 📋 "/menu" — Display bot commands
- 🏓 "/ping" — Check bot response
- ❤️ Modular command system
- ⚙️ Easy configuration
- 🚀 More features can be added later

🛠️ Tech Stack

- Node.js
- Baileys
- GitHub
- Supabase (optional)

📁 Project Structure

dhani-whatsapp-bot/
├── commands/
├── assets/
├── config.js
├── index.js
├── package.json
└── .gitignore

🔐 Configuration

Bot settings and owner information will be stored in the configuration files/environment variables.

Never upload passwords, API keys, or session credentials to GitHub.
